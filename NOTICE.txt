Optional AI generation
Google Gemma 4 E4B, Qwen3.5 9B and Qwen3.5 35B-A3B model weights use Apache-2.0.
The app offers pinned Gemma Q4_0 conversions by ggml-org and Qwen Q4_K_M
conversions by Unsloth, identifying
the converter separately from the original Qwen publisher. Model weights
are downloaded only when chosen and are not bundled in the application.
Each exact download is verified against its recorded size and SHA-256.

The bundled llama.cpp inference engine uses MIT, with its original licence
and third-party component notices retained. Its binary release, source
revision and archive checksums are pinned in Desktop/ai/catalogue.json.
The matching inference source archive is retained with release materials.
Model and engine licences do not replace the application GPL licence.

The playground uses the bridge's own syntax reference and supported-step
list as generation context. AI-generated scripts still require review and
FileMaker testing. The app does not execute generated scripts in a database.

Local PDF script attachments
Mozilla PDF.js 6.4.299 (Apache-2.0) reads selectable PDF text on device.
Its compatibility build includes core-js 3.50.0 (MIT); original CMap and
font notices are retained with the vendored assets and in the offline viewer.
Exact package integrity and individual file SHA-256 values are recorded in
Desktop/notices/pdfjs/SOURCE.json. No PDF rendering scripts or document
JavaScript are executed. Attached text remains in memory until removed or
until the app closes; the original PDF is not changed or uploaded.
